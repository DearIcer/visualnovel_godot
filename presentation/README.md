# 项目介绍演示（HTML 幻灯片）

双击 `index.html` 用浏览器打开，点击中央播放按钮开始（含配乐）。约 70 秒自动播放完整 10 页。

## 操作

| 操作 | 效果 |
|---|---|
| 点击画面 / → / 空格 | 下一页 |
| ← | 上一页 |
| M / 右下按钮 | 音乐开关 |
| 右下「自动播放」 | 暂停/恢复自动翻页 |
| 右下「重播」 | 回到第一页 |

## 调试参数

- `?autoplay=0`：关闭自动播放并隐藏开始遮罩
- `?slide=N`：直接定位到第 N 页（0 起）

## 素材来源

- `assets/bgm.ogg`：「chill guitar」— D-Wheat Music（itch.io，免费可用于个人与商业用途）
- `assets/title.png` / `mio_*.png` / `street_night.png`：示例 Demo《红线缠心》的 AI 生成素材（gemini-nano-banana-2.1）

## 录制为视频

如需导出 mp4：全屏播放后用 OBS / Xbox Game Bar（Win+G）录屏即可；页面为 1600×900 逻辑分辨率，任意窗口大小下自动等比缩放。
